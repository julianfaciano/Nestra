# Dominio (reservado para Fase 1)

Aquí vivirán tipos y reglas puras de producción, sin React, IPC ni persistencia.
Todavía no hay entidades implementadas.

Primera entrega prevista, después de revisar Fase 0:

- Unidades físicas explícitas en mm y conversiones mm/cm, con tests.
- CanvasProfile y configuración de Imprenta/Calandra.
- Máximos configurables; Calandra nunca podrá superar 5000 mm de alto.
- Validación de números finitos, positivos y límites. Los máximos no son tamaños obligatorios.

Las geometrías no dependerán de píxeles ni del PPI de salida.
